# MediSync Healthcare Portal

A role-aware healthcare portal demo for appointments, medical records, and billing, built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Demo features

- Patient dashboard, appointment booking, medical records, and mock payments
- Doctor schedule, patient history, prescription builder, and report review
- Admin room allocation, walk-in registration, billing reconciliation, and audit logs
- Role switcher and shared demo state persisted in browser `localStorage`

## Important

This is a front-end demonstration, not a production healthcare system. It uses sample data and simulated authentication, records, and payments. It does not provide real JWT/MFA authentication, secure medical data storage, or payment processing. Do not enter real patient information or credentials.
